# 📧 TempMail Client

### Modern Temporary Email Application

TempMail Client is a modern and responsive web application that allows users to generate temporary email addresses and receive emails without using their personal inbox.

The application provides a simple interface for creating disposable email addresses, monitoring the temporary inbox, refreshing messages, and managing the temporary mailbox lifecycle.

---

## ✨ Features

* 📧 Generate temporary email addresses
* 📥 Receive emails in a temporary inbox
* 🔄 Refresh inbox for new messages
* ➕ Generate a new temporary email
* ⏳ Temporary mailbox expiration timer
* 🗑️ Delete/clear inbox
* 📋 Copy temporary email address
* 📱 Responsive and modern user interface
* 🔒 Designed for privacy-focused disposable email usage

---

## 🖥️ Application Overview

The application includes:

### Temporary Email Address

Users can generate a disposable email address and copy it with a single click.

### Temporary Inbox

Incoming messages are displayed inside the temporary mailbox.

### Mailbox Management

Users can refresh the inbox, create a new temporary address, and clear the inbox when required.

### Expiration System

Temporary addresses have a limited lifetime, helping keep disposable mailboxes temporary.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/yasirrehman274/temp-mail-client.git
```

### 2. Navigate to the project

```bash
cd temp-mail-client
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

The application will then be available through the local development URL provided by Vite.
